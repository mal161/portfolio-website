# Alex Mwangi portfolio

A responsive, single-page React portfolio built with Vite. The page includes the hero, about, selected projects with case-study dialogs, technology, experience, process, contact, and footer sections.

## Run locally

npm install
npm run dev

## Production build

npm run build
npm run preview

Project images and the original hero texture are in public/assets. The page fonts load from Google Fonts.
